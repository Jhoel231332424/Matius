# Matius CRO Skill

Use when changing copy, CTA hierarchy, product cards, store blocks, Hero actions, trust content or WhatsApp behavior.

## Primary conversion

WhatsApp consultation.

Do not optimize for fake urgency or checkout behavior that does not exist.

## Funnel

`discover → desire → understand quality → trust → WhatsApp`

Every section must advance at least one step.

## CTA hierarchy

Primary intent examples:
- `Descubrir zapatos`
- `Consultar disponibilidad`
- `Hablar por WhatsApp`

Secondary actions must not visually compete with the main action.

## Contextual WhatsApp

Preserve/extend event sources:
- hero;
- product;
- store;
- final-cta;
- floating;
- general.

Prefer contextual messages using verified names (product/store) rather than generic “Hola”.

## Trust

Use only real proof:
- Cochabamba/Bolivia presence;
- physical stores when verified;
- official product/price data;
- real brand/process facts.

Never create fake reviews, star ratings, countdowns, low-stock labels or invented guarantees.

## Review checklist

For every block ask:
1. What is being sold?
2. Why should the visitor care?
3. What new trust is created?
4. What is the next action?
5. Is the CTA proportional to user intent at this point?
6. Is WhatsApp copy contextual?
7. Can the section be removed without hurting desire/trust/conversion? If yes, consider removing it.

## Mobile conversion

- primary CTA reachable without precision tapping;
- 44 px minimum target;
- floating WhatsApp must not cover CTA;
- avoid excessive CTA repetition within one viewport;
- product CTA remains attached to product context.

## Analytics

Do not rename existing events casually. If a new source is introduced, document it and keep event naming stable.

## Done

- copy is truthful;
- CTA hierarchy is obvious;
- WhatsApp source is trackable;
- no fake proof;
- mobile CTA tested;
- snapshots/CI reviewed when UI changes.
